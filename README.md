Bellumiê Cupcakes Gourmet

Projeto acadêmico de uma loja virtual de cupcakes gourmet, desenvolvido para aplicar conhecimentos de desenvolvimento web, banco de dados e testes de software.

Sobre o projeto

O sistema permite que clientes visualizem os cupcakes disponíveis, adicionem produtos ao carrinho e realizem pedidos informando seus dados de entrega e pagamento.

O projeto também possui uma área administrativa para gerenciar produtos e acompanhar os pedidos recebidos.

Funcionalidades

Catálogo de produtos carregado do banco de dados.

Carrinho de compras.

Finalização de pedidos.

Cadastro, edição e exclusão de produtos na área administrativa.

Visualização e atualização do status dos pedidos.

Armazenamento de produtos e pedidos utilizando SQLite.

Tecnologias utilizadas

Python

Flask

SQLite

HTML

CSS

JavaScript

Como executar o projeto localmente

Instale o Python.

Baixe ou clone este repositório.

Abra um terminal na pasta do projeto.

Instale a dependência:

pip install -r requirements.txt

Execute a aplicação:

python app.py

Abra http://127.0.0.1:5000 no navegador.

Observação

Este projeto foi desenvolvido para fins acadêmicos. Os pedidos são armazenados no banco de dados local SQLite.
