    Conheça a Bellumiê

    A Bellumiê Cupcakes Gourmet é um projeto acadêmico que une criatividade, tecnologia e o universo dos doces artesanais.

    Nossa proposta é oferecer uma experiência simples e agradável para conhecer sabores, montar pedidos e descobrir o encanto dos nossos produtos.

    Este site foi desenvolvido para fins acadêmicos, como parte de um projeto de Engenharia de Software.
